## catweb :3

meow

a browser im making in rust because apparently i have nothing better to do

it’s purple, has a cat, blocks ads, and actually works (most of the time)

# features

* built-in adblocker and tracker blocking
* customizable themes and ui
* webview2 for normal browsing
* catweb native, my own rendering engine written in rust
* silly settings (meow button included)
* a cat named tuft
* can be set as your default browser on windows
* other stuff im probably forgetting

# webview2 (default)

this uses microsoft’s webview2 engine, so most websites should work normally.

webview2 has established security protections, but catweb itself is still new and hasn’t been independently security audited.

i’d avoid using it for banking or anything involving really sensitive information for now.

# catweb native

this is the rendering engine im building myself.

it’s cool but also very unfinished.

# PLEASE don’t sign into your accounts or enter sensitive information while using this engine.

it’s still being tested and isn’t properly secured yet.

# use webview2 for normal browsing.
